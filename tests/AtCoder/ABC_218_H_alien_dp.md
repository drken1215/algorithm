## 問題概要
$N$ 個のランプ $1, 2, \dots, N$ が一列に並んでいて、そのうち $R$ 個を赤色に塗り、$N-R$ 個を青色に塗る。

各 $i = 1, 2, \dots, N-1$ について、ランプ $i, i+1$ が異なる色で光っているとき、$A_i$ だけ報酬を得る。

ランプの色を適切に定めたときに得られる報酬の合計の最大値を求めよ。


## 制約

- $2 \le N \le 2 \times 10^{5}$


## 解法メモ

### 制約「$R$ 個を赤色に塗る」がない場合
$R$ 個を赤色に塗るという制約がなければ、次の DP が考えられる。

+ `dp[i]` := 先頭から $i$ 個のランプの色を決める。ここで、最後のランプの色を赤色で塗るとしたときについての、報酬の $-1$ 倍の最小値

として、

`dp[j] = min_{i < j} (dp[i] + f(i, j))`

ここで、

----
$f(i, j)$ := ランプ $i-1$ を赤色で塗ったあとに、ランプ $i, i+1, \dots, j-2$ を青色にして、ランプ $j-1$ を赤色に塗ったときに発生する報酬の $-1$ 倍

----

である。$f(i, j)$ は次のように求められる。

```cpp
auto cost = [&](int i, int j) -> long long {
    if (j - i <= 1) return 0;
    if (i == 0) return -A[j - 2];
    else return -A[i - 1] - A[j - 2];
};
```

関数 $f$ は Monge であるから、LARSCH 法によって $O(N)$、Simple LARSCH 法によって $O(N \log N)$ の計算量で解くことができる。


### 制約「$R$ 個を赤色に塗る」を考慮する
この制約を考慮すると、辺 $(i, j)$ のコストが $f(i, j)$ であるような DAG において、

+ 末尾のランプを赤色に塗る場合：**ちょうど $R$ 本の辺を含む**ようなパスの最短路長を求める問題
+ 末尾のランプを青色に塗る場合：**ちょうど $N - R$ 本の辺を含む**ようなパスの最短路長を求める問題 (上の DP で赤色と青色の役割を入れ替える)

であると考えることができる。これらのうちの良い方を採用すればよい。また、このようにちょうど $d$ 本の辺を含む Monge 単一始点最短路を求める問題は Alien DP によって解くことができる。

下のコードでは、Monge 単一始点最短路問題を解く部分に Simple LARSCH 法を用いており、全体の計算量は $O(N \log^{2} N)$ となる。
