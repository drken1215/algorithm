## 概要
素数 $p$ についての有限体 $\mathbb{F}_p$ を表す構造体である。

### 有限体 $\mathbb{F}_p$ とは
有限体 $\mathbb{F}_p$ とは「**素数 $p$ で割った余りの世界**」を表すものである。以下の $p$ 個の要素からなる集合である。

- $p$ で割った余りが $0$ となる整数の集まり
- $p$ で割った余りが $1$ となる整数の集まり
- $\dots$
- $p$ で割った余りが $p-1$ となる整数の集まり

たとえば、カレンダーの曜日は、$\mathbb{F}_{7}$ ($p = 7$ としたもの) を表すものといえる。

### 有限体 $\mathbb{F}_p$ の要素同士の演算
有限体 $\mathbb{F}_p$ の要素同士で、「足し算」「引き算」「掛け算」「割り算」という演算もできる。なお、これ以降は「$p$ で割った余りが $r$ となる整数の集まり」のことを単に $r$ と書くこととする。

たとえば $p = 13$ のとき、次のようになる。

- $6 + 9 = 2$
- $6 - 9 = 10$
- $6 \times 9 = 12$
- $6 \div 9 = 5$

最後の式のみ直感的ではないが、$5 \times 9 = 6$ であり、「割り算は掛け算の逆」であることから $6 \div 9 = 5$ が導かれる。


## 使用例
競技プログラミングにおいては、「$998244353$ で割った余りを求めよ」という形式の問題が出題されることが多々ある。たとえば、$n = 423343$ として、求めたい値が

$\frac{(n-1)n(n+1)}{6}$ を $998244353$ で割った余り

であるとき、次のコードのように求められる。`274730459` と出力される。

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "modint.hpp"

int main() {
    using mint = Fp<998244353>;
    mint n = 423343;
    mint res = (n - 1) * n * (n + 1) / mint(6);
    cout << res << endl;
}
```
